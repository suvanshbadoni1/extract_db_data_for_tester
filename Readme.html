System Overview

Purpose: Unified web interface to search, view, and analyze transaction data across three different banking databases.
PRM (MSSQL)

Primary transaction storage with DETAIL table. Uses DD_APDATE for date filtering.

Search: PAN (sd_pan), RRN (SD_REF_NUM)
UPF (Oracle)

Payment processing logs in ep_log table. JSON data in ext column.

Search: STAN, RRN (JSON), PAN (masked)
EPS (Oracle)

PTLF records in SFRTFPOSREG table. Custom parser removes 85-byte header.

Search: PAN, CTX_KEY

Key Features

  • Unified search interface
  • Real-time database status
  • Complete PTLF parser (Java-compatible)
  • Date range filtering
  • Vertical card layout (no horizontal scroll)
  • Copy to clipboard functionality
  • Expand/Collapse all records
  • JSON syntax highlighting

PTLF Parser Documentation

What is PTLF?
PTLF (Payment Transaction Logging Format) is a proprietary message format developed by Westpac for recording financial transaction data in their EPS database.

Message Structure

! B000123[123 bytes of B0 data] ! QP00344[344 bytes of QP data] ! QS00059[59 bytes of QS data]

Token Format Specification

ComponentLengthDescriptionExample
Start Marker2 charsAlways ! !
Token ID2 charsIdentifies token typeB0, QP, QS
Length Field5 charsLength of value (zero-padded)00123
Value FieldVariableActual token dataBNET010143025...

Token Types Summary

TokenPurposeKey FieldsLength
B0Base TransactionCard Number, Response Code, Date/Time~180 bytes
QPISO8583 PaymentAmount, Merchant Name, Approval Code~344 bytes
QSTiming DataEntry/Exit Timestamps, Processing Times~59 bytes
QCVariable FieldsDynamic data fieldsVariable
BECurrency ConversionCurrency Code, Conversion Rate~62 bytes
SNSub-tokensNested token dataVariable

B0 Token (Base Transaction) - Critical Fields

FieldOffsetDescriptionValues
RESPCDE26-28Response Code00=Approved, 01=Declined, 05=Do Not Honor
CARD_NUMBER164-180PAN16-digit card number (masked)
PROCCDE32-38Processing Code000000=Purchase, 200000=Refund
LOCALTIM10-16Transaction TimeHHMMSS format
LOCALDAT16-20Transaction DateDDMMYY format

FieldDescriptionExample
